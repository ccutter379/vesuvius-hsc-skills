# Answering HSC Questions — Cities of Vesuvius

A revision website for the NSW Ancient History Stage 6 (Year 12) Core Study:
**Cities of Vesuvius — Pompeii and Herculaneum.**

It models the *thinking* behind a strong HSC answer. Eight worked question sets,
at 3, 4, 5, 6, 7, 8, 10 and 12 marks, each pairing one written source with one
image of archaeological evidence, and each worked through in four moves:

1. **Deconstruct the sources** — origin, nature and purpose, content, value, limitations, plus how to read an archaeological image.
2. **Deconstruct the question** — the directive verb, scope, cities named, mark value translated into length, what the marker wants, and how students lose marks.
3. **The modelled response** — written at HSC standard, then annotated sentence by sentence to show what each move is doing and why it earns marks.
4. **Your turn** — a parallel question on the same skill with different evidence, and a self-marking checklist instead of an answer.

Reference sections cover the NESA directive verbs, integrating source evidence
into a paragraph (weak versus strong versions side by side), sixteen common
mistakes with fixes, and a practice question bank.

## Using it

Open the page and work through a set. Attempt the question **before** opening
the *Reveal the model answer* toggle — reading a model answer you haven't
attempted teaches very little. The orange margin notes are the actual lesson;
the top bar can hide them so you can re-read an answer clean.

Everything expands automatically when printed, and images convert to greyscale,
so any set can be printed as a handout.

## Technical

A single `index.html` with no build step, no framework, no external scripts,
fonts or trackers. It works offline once loaded — download the repository and
open `index.html` from disk if you prefer.

## Sources and accuracy

Every source named is a real source with a real citation. Nothing is invented.
Where the exact wording of a translation could not be verified, the text is
given as a clearly labelled summary rather than inside quotation marks. Where
scholars genuinely disagree — the eruption date, the function of the Building of
Eumachia, how competitive the elections really were — the disagreement is
presented as a disagreement.

Three images are records rather than remains, and their captions say so: the
electoral notices are a nineteenth-century watercolour copy, the Street of the
Tombs is an 1830 engraving, and the Alexander Mosaic is photographed as the
modern copy laid in its original position.
